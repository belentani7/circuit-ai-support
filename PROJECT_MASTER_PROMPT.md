> Canonical repository: `belentani7/circuit-ai-support`.
> Brand/product: **CIRCUIT — operational modernization**. Max is the horse-leg character representing reliable, deliberate progress.
> Promise: **No cambio tu negocio. Cambio la forma en que funciona por dentro.**

## Authority and boundaries

The brand doctrine and operating rules are in `docs/CIRCUIT_MAX_PROTOCOL.md` and `internal/CIRCUIT_OS_PRODUCT.md`. Do not mistake this product for a generic chatbot, a replacement for another business, or a public SaaS. Keep internal operational documents in internal paths. Preserve authorial branding. The website sells *diagnosis, improved processes, implementation and measured outcomes*, not fictional autonomous agents.

## Maximum coherent destination

- A high-quality, fast, responsive branded website for CIRCUIT Essential, Private, Care and Playbook Sprint, with clear service explanations, human-approved price boundaries and genuine contact intake.
- Structured discovery: input validation, missing-field questions, consent, work-process description and triaged request record; configurable owned integrations, no speculative CRM connectivity.
- Operational maps and diagnostics: editable process steps, bottleneck classification, evidence, baseline and after measurements, risks, assumptions, responsible operator and next action.
- Full staged delivery: diagnosis report, improvement proposals, human approval, implementation tasks and monitorable follow-up.
- CIRCUIT OS retained as private internal modules: CRM, diagnosis, architect, proposal, builder, knowledge, decision ledger, metrics and exception review. Access control must precede anything that reads or edits client data.
- Max Protocol P1–P7 enforcement: validated inputs, approved context, clear intention, reversible proposal, risk assessment, human review for sensitive actions, traceability.
- A draft-only chat/email assistant with sources and human approval; never auto-send contracts, price commitments, access decisions, sensitive legal communications or health information.
- Appropriate visual identity and content: Max, dark archival aesthetic, strong information hierarchy, no missing assets, real case studies clearly separated from simulated examples. Pricing, benchmark scores and vendor rates must be timestamped or marked illustrative.

## Actual code and iteration contract

Existing project is React/TypeScript/Vite `client/` with Express `server/` and pnpm lockfile. Preserve this repo and strengthen it instead of launching duplicates. The existing website is largely a research/concept experience; do not claim a working backend diagnostic pipeline.

1. Correct broken website behavior/assets and misleading claims. Make copy/template interactions dependable on browsers without Clipboard API.
2. Connect an accessible form to a validated private intake endpoint with secure storage only after environment and data-protection decisions are made; add spam abuse controls.
3. Implement human-reviewable diagnosis and map outputs, with clear operational status; add true internal authentication and authorization before CIRCUIT OS data access.
4. Integrate sanctioned external systems only when permissions, consent, minimal storage and rollback are validated.
5. Release: `pnpm install --frozen-lockfile`, `pnpm check`, `pnpm exec vitest run`, `pnpm build`, end-to-end smoke test in supported browser and review of real deployment. Record what passed and did not pass.

## Rules for future code agents

Work on this repository one functional increment at a time. Read the source of truth first, implement working paths, test regression cases, commit accurately and track deployment evidence. Avoid endless audits, speculative claims, fake statistics, invented integrations and copying private information to public infrastructure. No new repository or unsolicited changes in visibility.
